# 配置说明

本文整理当前项目的关键环境变量、端口和依赖关系。事实来源为 `deploy/env/chatserver.env.example`、`docker-compose.yml` 和各服务启动配置。

## 1. 配置来源

| 来源 | 用途 |
| --- | --- |
| `deploy/env/chatserver.env.example` | 本地与容器运行的标准模板。 |
| `deploy/env/chatserver.env` | 本地实际运行配置。 |
| `docker-compose.yml` | 容器内服务默认覆盖值。 |
| 各服务 `cmd` / `config` | 代码默认值与运行时回退。 |

原则：

1. 文档中只写字段语义，不写真实敏感值；
2. 真实账号、密码、SMTP 授权码只能写入本地 `.env` 或部署平台；
3. 变更环境变量时必须同步更新模板和本文。

## 2. 基础设施配置

### 2.1 MySQL

| 变量 | 说明 |
| --- | --- |
| `MYSQL_DSN` | 应用使用的 MySQL DSN。 |
| `MYSQL_HOST` / `MYSQL_PORT` | MySQL 地址。 |
| `MYSQL_USER` / `MYSQL_PASSWORD` | MySQL 账号密码。 |
| `MYSQL_DATABASE` | 数据库名，默认 `chat_server`。 |
| `MYSQL_LOG_LEVEL` | SQL 日志级别。 |

### 2.2 Redis

| 变量 | 说明 |
| --- | --- |
| `REDIS_HOST` / `REDIS_PORT` | Redis 地址。 |
| `REDIS_ADDR` | Redis 组合地址。 |
| `REDIS_PASSWORD` | Redis 密码。 |
| `REDIS_DB` | Redis DB 编号。 |
| `REDIS_POOL_SIZE` | 连接池大小。 |
| `REDIS_MIN_IDLE_CONNS` | 最小空闲连接。 |

| 变量 | 说明 |
| --- | --- |

| `KAFKA_RETRY_GROUP_ID` | Redis 重试消费者组。 |

| `KAFKA_MSG_PUSH_TOPIC` | 消息下行 topic。 |
| `KAFKA_MSG_PUSH_GROUP_ID` | message-push 消费组。 |
| `KAFKA_GROUP_CACHE_TOPIC` | 群缓存投影 topic。 |
| `KAFKA_GROUP_CACHE_GROUP_ID` | 群缓存投影消费者组。 |

| `DEBEZIUM_CONNECTOR_NAME` | Debezium 连接器名称。 |
| `DEBEZIUM_TOPIC_PREFIX` | Debezium topic 前缀。 |

## 8. 修改配置时的同步要求

以下变更必须同步更新文档：

1. 新增环境变量：更新 `chatserver.env.example`、本文、必要的服务文档；
2. 修改默认 topic / 端口：更新 `data/Kafka事件.md`、`ops/本地运行与手工测试.md`；
3. 修改 WebSocket 白名单或路由 TTL：更新 `api/06-WebSocket协议.md` 与相关链路文档；
4. 修改邮件、MinIO、Debezium 配置：更新对应 `ops/` 文档。
