# Gateway 监控集成说明
## 📊 监控架构
采用业界标准的 **Prometheus + Grafana** 监控方案：
- **Prometheus**：负责收集和存储监控数据（每 15 秒拉取一次）
- **Grafana**：负责数据可视化展示
## 🚀 已实现的监控指标
### HTTP 监控指标
| 指标名称 | 类型 | 说明 | 标签 |
|---------|------|------|------|
| `gateway_http_requests_total` | Counter | HTTP 请求总数 | method, path, status |
| `gateway_http_request_duration_seconds` | Histogram | HTTP 请求耗时分布 | method, path |
| `gateway_http_request_size_bytes` | Histogram | HTTP 请求体大小分布 | method, path |
| `gateway_http_response_size_bytes` | Histogram | HTTP 响应体大小分布 | method, path |
| `gateway_http_requests_in_progress` | Gauge | 当前正在处理的请求数 | method |
### gRPC 监控指标
| 指标名称 | 类型 | 说明 | 标签 |
|---------|------|------|------|
| `gateway_grpc_requests_total` | Counter | gRPC 请求总数 | service, method, status |
| `gateway_grpc_request_duration_seconds` | Histogram | gRPC 请求耗时分布 | service, method |

## 🔧 Prometheus 配置
### 1. 安装 Prometheus
#### Linux/Mac
```bash
# 下载 Prometheus
wget https://github.com/prometheus/prometheus/releases/download/v2.45.0/prometheus-2.45.0.linux-amd64.tar.gz
tar xvfz prometheus-2.45.0.linux-amd64.tar.gz
cd prometheus-2.45.0.linux-amd64
# 启动 Prometheus
./prometheus
```
#### Docker
```bash
docker run -d \
  --name=prometheus \
  -p 9090:9090 \
  -v /path/to/prometheus.yml:/etc/prometheus/prometheus.yml \
  prom/prometheus
```
### 2. 配置 Prometheus（prometheus.yml）
```yaml
global:
  scrape_interval: 15s  # 每 15 秒拉取一次数据
  evaluation_interval: 15s
scrape_configs:
  # Gateway 服务监控
  - job_name: 'chatserver-gateway'
    static_configs:
      - targets: ['localhost:8080']
        labels:
          service: 'gateway'
          environment: 'development'
  # 如果有其他服务（如 user-service），也在这里配置
  - job_name: 'chatserver-user-service'
    static_configs:
      - targets: ['localhost:9090']
        labels:
          service: 'user-service'
          environment: 'development'
```
### 3. 启动 Prometheus
```bash
# 使用配置文件启动
./prometheus --config.file=prometheus.yml
```
访问 http://localhost:9090 即可查看 Prometheus UI。
### 4. 验证数据采集
在 Prometheus UI 中执行以下查询，确认数据正常：
```promql
# HTTP 请求总数
rate(gateway_http_requests_total[1m])
# HTTP 请求 P95 耗时
histogram_quantile(0.95, rate(gateway_http_request_duration_seconds_bucket[5m]))
# 当前正在处理的请求数
gateway_http_requests_in_progress
```
## 📈 Grafana 可视化配置
### 1. 安装 Grafana
#### Docker（推荐）
```bash
docker run -d \
  --name=grafana \
  -p 3000:3000 \
  grafana/grafana
```
访问 http://localhost:3000，默认账号密码：`admin/admin`
### 2. 添加 Prometheus 数据源
1. 登录 Grafana → Configuration → Data Sources → Add data source
2. 选择 "Prometheus"
3. 填写 URL：`http://localhost:9090`
4. 点击 "Save & Test"
### 3. 创建 Dashboard
#### 示例查询语句
**面板 1：HTTP 请求速率（QPS）**
```promql
sum(rate(gateway_http_requests_total[5m])) by (path)
```
**面板 2：HTTP 请求 P95 耗时**
```promql
histogram_quantile(0.95, sum(rate(gateway_http_request_duration_seconds_bucket[5m])) by (le, path))
```
**面板 3：HTTP 错误率**
```promql
sum(rate(gateway_http_requests_total{status=~"5.."}[5m])) by (path)
```
**面板 4：HTTP 请求分布**
```promql
sum(rate(gateway_http_requests_total[5m])) by (status)
```
**面板 5：当前并发请求数**
```promql
sum(gateway_http_requests_in_progress) by (method)
```
**面板 6：gRPC 请求 P95 耗时**
```promql
histogram_quantile(0.95, sum(rate(gateway_grpc_request_duration_seconds_bucket[5m])) by (le, method))
```
### 4. 导入预置 Dashboard
Grafana 提供了很多现成的模板，可以直接导入：
1. 访问 https://grafana.com/grafana/dashboards/
2. 搜索 "Gin" 或 "HTTP API"
3. 找到合适的 Dashboard，复制 ID
4. 在 Grafana 中：Create → Import → 输入 ID
推荐 Dashboard：

- **ID: 16098** - Prometheus HTTP Statistics
## 🎯 监控最佳实践
### 1. 关键指标关注点
- **P95/P99 耗时**：超过 500ms 需要关注
- **错误率**：错误率超过 1% 需要告警
- **QPS**：异常波动可能表示攻击或故障
- **并发数**：突然飙升可能表示服务卡顿
### 2. 告警规则示例（prometheus.yml）
```yaml
groups:
  - name: chatserver_alerts
    interval: 30s
    rules:
      # HTTP P95 耗时告警
      - alert: HighHTTPLatency
        expr: histogram_quantile(0.95, sum(rate(gateway_http_request_duration_seconds_bucket[5m])) by (le, path)) > 0.5
        for: 5m
        labels:
          severity: warning
        annotations:
          summary: "HTTP P95 耗时过高"
          description: "接口 {{ $labels.path }} 的 P95 耗时超过 500ms"
      # HTTP 错误率告警
      - alert: HighHTTPErrorRate
        expr: sum(rate(gateway_http_requests_total{status=~"5.."}[5m])) by (path) / sum(rate(gateway_http_requests_total[5m])) by (path) > 0.01
        for: 5m
        labels:
          severity: critical
        annotations:
          summary: "HTTP 错误率过高"
          description: "接口 {{ $labels.path }} 的错误率超过 1%"
      # 服务不可用告警
      - alert: ServiceDown
        expr: up{job="chatserver-gateway"} == 0
        for: 1m
        labels:
          severity: critical
        annotations:
          summary: "Gateway 服务不可用"
```
## 📝 自定义指标
如果需要添加新的监控指标，参考以下步骤：
### 1. 在 `metrics.go` 中定义指标
```go
// 新的指标
var myCustomMetric = promauto.NewCounterVec(
    prometheus.CounterOpts{
        Name: "gateway_custom_metric",
        Help: "Description of my custom metric",
    },
    []string{"label1", "label2"},
)
```
### 2. 在代码中使用
```go
// 增加计数
myCustomMetric.WithLabelValues("value1", "value2").Inc()
// 设置值（对于 Gauge）
myCustomMetric.WithLabelValues("value1", "value2").Set(42)
```
### 3. 验证指标
访问 `/metrics` 接口，确认新指标出现。
## 🚨 故障排查
### 问题 1：/metrics 接口无数据
**可能原因**：
- 中间件未正确注册
- 服务未启动
**解决方法**：
- 检查路由配置，确认 `PrometheusMiddleware()` 已添加
- 确认服务已启动并监听正确端口
### 问题 2：Prometheus 无法拉取数据
**可能原因**：
- 端口配置错误
- 网络不通
**解决方法**：
- 检查 `prometheus.yml` 中的 targets 配置
- 使用 curl 测试：`curl http://localhost:8080/metrics`
### 问题 3：Grafana 无法显示数据
**可能原因**：
- 数据源配置错误
- 查询语句有误
**解决方法**：
- 检查数据源 URL 是否正确
- 在 Prometheus UI 中先验证查询语句
