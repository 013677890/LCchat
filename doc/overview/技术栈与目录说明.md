# 技术栈与目录说明

## 技术栈

| 技术 | 用途 |
| --- | --- |
| Go 1.25 | 后端服务开发语言。 |
| Gin | Gateway 和 Connect HTTP/WebSocket 入口。 |
| gRPC + Protobuf | 服务间同步 RPC 契约。 |
| GORM | MySQL 数据访问。 |
| Redis Stack Server | Token、缓存、限流、路由、幂等、ACK，以及 RedisBloom 存在性索引。 |
| Kafka | 跨服务事件和消息下行事件。 |
| Kafka Connect + Debezium | Outbox CDC（变更数据捕获）链路。 |
| MinIO | 头像等对象存储。 |
| Zap | 结构化日志。 |
| Prometheus | 指标暴露与采集。 |
| Wire | 依赖注入代码生成。 |

## 顶层目录

| 目录 | 职责 |
| --- | --- |
| [apps](../../apps) | 各业务服务，每个服务有独立 `cmd` 入口。 |
| [proto](../../proto) | Protobuf 源文件，是 gRPC 与部分 WebSocket 二进制帧的契约来源。 |
| [model](../../model) | GORM 数据模型。 |
| [pkg](../../pkg) | 公共基础库，例如日志、错误、Redis、Kafka、gRPC、Outbox、MinIO。 |
| [config](../../config) | 配置加载与默认值。 |
| [consts](../../consts) | 错误码、错误消息、Redis Key 构造。 |
| [deploy](../../deploy) | 环境变量模板和部署相关文件。 |
| [scripts](../../scripts) | CDC 初始化、迁移等脚本。 |
| [doc](../README.md) | 当前项目文档。 |

## 服务目录约定

每个 `apps/<service>` 目录通常包含：

| 子目录 | 职责 |
| --- | --- |
| `cmd` | 服务启动入口、依赖装配、生命周期管理。 |
| `internal/handler` | gRPC 或 HTTP 薄处理层，负责参数转换和错误映射。 |
| `internal/service` | 领域服务或业务服务。 |
| `internal/repository` | 数据访问和缓存访问。 |
| `internal/consumer` | Kafka 消费者或后台任务。 |
| `internal/*cli` | 访问其他服务的客户端封装。 |

不同服务会按自身职责增减目录，例如 msg 使用 `internal/domain` 和 `internal/usecase` 表达 DDD（领域驱动设计）分层，connect 使用 `internal/manager` 管理本地连接。

## 公共库重点

| 包 | 职责 |
| --- | --- |
| `pkg/apperr` | 业务错误封装、跨 gRPC 传输和脱敏。 |
| `pkg/grpcx` | gRPC 服务端和客户端公共能力，例如日志、超时、重试。 |
| `pkg/logger` | 结构化日志。 |
| `pkg/kafka` | Kafka Producer、普通 Consumer、手动提交 Consumer。 |
| `pkg/outbox` | CDC Outbox 事件落库和幂等消费记录。 |
| `pkg/presence` | 在线路由（presence）共享读取契约：解析、窗口过滤与默认参数。 |
| `pkg/minio` | 对象存储客户端。 |
| `pkg/result` | Gateway HTTP 统一响应。 |
| `pkg/ctxmeta` | trace_id、user_uuid、device_id、client_ip 等上下文元数据。 |

## 契约优先级

- HTTP 路由以 [apps/gateway/internal/router/router.go](../../apps/gateway/internal/router/router.go) 为准。
- gRPC 字段和枚举以 [proto](../../proto) 为准。
- 错误码以 [consts/const.go](../../consts/const.go) 为准。
- Redis Key 以 [consts/redisKey](../../consts/redisKey) 为准。
- 数据库表以 [model](../../model) 与 [config/mysql/001_schema.sql](../../config/mysql/001_schema.sql) 为准。
