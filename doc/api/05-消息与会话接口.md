# 消息与会话接口

本文描述消息发送、历史拉取、消息反查、撤回、会话列表、已读、删除会话和会话设置接口。所有接口均需要登录态，响应结构遵循 [接口通用规范](00-接口通用规范.md)。字段名以 Gateway DTO 的 JSON 标签为准。

## 1. 模块约定

### 1.1 路由与认证

| 能力 | 路由前缀 | 是否需要登录 | 说明 |
| --- | --- | --- | --- |
| 消息 | `/api/v1/auth/messages` | 是 | 发送、拉取、反查、撤回消息。 |
| 会话 | `/api/v1/auth/conversations` | 是 | 会话列表、标记已读、删除会话、更新设置。 |

所有接口必须携带：

```http
Authorization: Bearer <access_token>
X-Device-ID: <device_id>
```

`X-Device-ID` 会参与消息发送幂等（同一 `fromUuid + deviceId + clientMsgId` 不重复落库），前端必须保证同一设备稳定使用同一个设备 ID。

### 1.2 枚举约定

| 枚举 | 值 | 说明 |
| --- | --- | --- |
| `convType` | `1` | 单聊，`targetUuid` 为对端用户 UUID。 |
| `convType` | `2` | 群聊，`targetUuid` 为群 UUID。 |
| `direction` | `0` | 未指定，等同向后拉取新消息。 |
| `direction` | `1` | 向后拉取，返回 `seq > anchorSeq` 的消息。 |
| `direction` | `2` | 向前拉取，返回 `seq < anchorSeq` 的历史消息。 |
| 消息 `status` | `0` | 正常。 |
| 消息 `status` | `1` | 已撤回。 |
| 消息 `status` | `2` | 已删除。 |

### 1.3 通用消息对象

`MsgItemDTO`：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `msgId` | string | 服务端生成的全局消息 ID。 |
| `clientMsgId` | string | 客户端生成的幂等 ID。 |
| `convId` | string | 会话 ID。单聊通常由双方 UUID 生成，群聊通常为群 UUID。 |
| `seq` | int64 | 会话内严格递增序号。 |
| `fromUuid` | string | 发送者 UUID。 |
| `msgType` | int32 | 消息类型，由前端业务自行约定内容解析方式。 |
| `content` | string | 消息内容 JSON 字符串。 |
| `status` | int32 | 消息状态，见 1.2。 |
| `sendTime` | int64 | 服务端发送时间，Unix 毫秒。 |
| `replyToMsgId` | string | 被回复消息 ID，空字符串表示非回复。 |
| `atUsers` | string[] | 被 @ 用户 UUID 列表；@全体可使用保留 UUID `00000000000000000000`。 |

`ConversationItemDTO`：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `convId` | string | 会话 ID。 |
| `convType` | int32 | 会话类型：1 单聊，2 群聊。 |
| `targetUuid` | string | 单聊为对端 UUID，群聊为群 UUID。 |
| `lastMsg` | object/null | 最后一条消息预览。 |
| `lastMsg.msgId` | string | 最后一条消息 ID。 |
| `lastMsg.previewJson` | string | 预览 JSON 字符串，前端按业务解析。 |
| `lastMsg.sendTime` | int64 | 最后一条消息发送时间，Unix 毫秒。 |
| `unreadCount` | int32 | 未读数。 |
| `mute` | bool | 是否免打扰。 |
| `pin` | bool | 是否置顶。 |
| `updatedAt` | int64 | 会话更新时间，Unix 毫秒。 |

## 2. 发送消息

| 项 | 值 |
| --- | --- |
| 方法 | `POST` |
| 路径 | `/api/v1/auth/messages/send` |
| 请求体 | JSON |
| 底层 RPC | `msg.MsgService.SendMessage` |
| 超时预算 | 3 秒 |

### 2.1 请求字段

`fromUuid` 和 `deviceId` 由 Gateway 从 JWT 和 `X-Device-ID` 注入，前端不要在 body 中传。

| 字段 | 类型 | 必填 | 约束 | 说明 |
| --- | --- | --- | --- | --- |
| `clientMsgId` | string | 是 | 非空，建议最长 64 | 客户端幂等 ID，建议使用 UUID/ULID。 |
| `convType` | int32 | 是 | 1、2 | 会话类型。 |
| `targetUuid` | string | 是 | 非空 | 单聊为对端 UUID，群聊为群 UUID。 |
| `msgType` | int32 | 是 | 服务端校验支持范围 | 消息类型。 |
| `content` | string | 是 | 非空，最大约 64KB | 消息内容 JSON 字符串。 |
| `replyToMsgId` | string | 否 | - | 回复目标消息 ID。 |
| `atUsers` | string[] | 否 | - | 被 @ 用户 UUID 列表。 |

### 2.2 请求示例

```json
{
  "clientMsgId": "web-1710000000000-0001",
  "convType": 1,
  "targetUuid": "10000000000000000002",
  "msgType": 1,
  "content": "{\"text\":\"你好\"}",
  "replyToMsgId": "",
  "atUsers": []
}
```

### 2.3 data 返回字段

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `msgId` | string | 服务端消息 ID。 |
| `seq` | int64 | 会话内序号。 |
| `convId` | string | 会话 ID。 |
| `sendTime` | int64 | 服务端发送时间，Unix 毫秒。 |

### 2.4 响应示例

```json
{
  "code": 0,
  "message": "success",
  "data": {
    "msgId": "msg_01HXX",
    "seq": 1024,
    "convId": "p2p_10000000000000000001_10000000000000000002",
    "sendTime": 1710000000123
  },
  "trace_id": "trace-xxx",
  "timestamp": 1710000000
}
```

### 2.5 幂等说明

同一用户、同一设备、同一 `clientMsgId` 重复提交不会重复持久化消息。客户端网络重试时应复用原 `clientMsgId`，不要重新生成，否则会被视为新消息。

## 3. 拉取消息

| 项 | 值 |
| --- | --- |
| 方法 | `GET` |
| 路径 | `/api/v1/auth/messages/pull` |
| 参数来源 | Query |
| 底层 RPC | `msg.MsgService.PullMessages` |
| 超时预算 | 2 秒 |

### 3.1 Query 参数

| 参数 | 类型 | 必填 | 默认值 | 约束 | 说明 |
| --- | --- | --- | --- | --- | --- |
| `convId` | string | 是 | - | 非空 | 会话 ID。 |
| `anchorSeq` | int64 | 否 | 0 | >= 0 | 拉取锚点。 |
| `limit` | int32 | 否 | 50 | 0-200 | 拉取数量，当前 Gateway 未传时默认 50。 |
| `direction` | int32 | 否 | 0 | 0、1、2 | 拉取方向，见 1.2。 |

示例：

```http
GET /api/v1/auth/messages/pull?convId=group_1&anchorSeq=100&limit=50&direction=1
```

### 3.2 data 返回字段

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `messages` | array | 消息列表，字段同 `MsgItemDTO`。 |
| `hasMore` | bool | 是否还有更多消息。 |
| `maxSeq` | int64 | 当前会话最大 seq。 |

### 3.3 前端拉取策略

1. 首次进入会话可传 `anchorSeq=0&direction=2` 拉历史，也可按产品策略拉最近消息。
2. 收到 WebSocket 下行时若发现 `seq` 不连续，应调用本接口按缺口补拉。
3. 会话被删除后服务端会用 `clearSeq` 过滤历史，前端不应期待被删除前的旧消息继续出现。

## 5. 撤回消息

| 项 | 值 |
| --- | --- |
| 方法 | `POST` |
| 路径 | `/api/v1/auth/messages/recall` |
| 请求体 | JSON |
| 底层 RPC | `msg.MsgService.RecallMessage` |
| 超时预算 | 2 秒 |

### 5.1 请求字段

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `convId` | string | 是 | 会话 ID。 |
| `msgId` | string | 是 | 要撤回的消息 ID。 |

成功时 `data=null`。撤回成功后服务端会异步投递 `MSG_RECALL` 下行通知，客户端也应立即乐观更新当前消息气泡为撤回状态。

| 超时预算 | 2 秒 |

### 6.1 Query 参数

| 参数 | 类型 | 必填 | 默认值 | 约束 | 说明 |

| `updatedSince` | int64 | 否 | 0 | >= 0 | 增量起始时间，Unix 毫秒；0 表示全量。 |

## 8. 删除会话

| 项 | 值 |
| --- | --- |
| 方法 | `DELETE` |
| 路径 | `/api/v1/auth/conversations/:convId` |
| 路径参数 | `convId` |
| 底层 RPC | `msg.MsgService.DeleteConversation` |
| 超时预算 | 2 秒 |

成功时 `data=null`。该操作是当前用户视角的逻辑删除，会记录清理位点，后续拉取会过滤删除前消息。

## 10. WebSocket 下行协作

消息 HTTP 接口只负责写入和查询，实时到达依赖 Connect WebSocket，详见 [WebSocket协议](06-WebSocket协议.md)。核心下行类型：

| 类型 | 说明 | 前端动作 |
| --- | --- | --- |
| `MSG_PUSH` | 新消息到达 | 插入消息列表，更新会话 `lastMsg` 和未读数。 |
| `MSG_RECALL` | 消息撤回 | 将目标消息改为撤回状态。 |
| `MSG_MARK_READ` | 已读多端同步 | 清除对应会话红点。 |
| `MSG_READ_RECEIPT` | 对端已读回执 | 更新发送消息的已读展示。 |

## 11. 前端接入注意事项

1. `content` 是 JSON 字符串，不是 JSON 对象；前端提交前需 `JSON.stringify`。
2. 发送失败但本地已有临时消息时，应根据 `clientMsgId` 合并服务端返回，避免重复气泡。
3. 收到 WebSocket 消息后如果本地不存在会话，应先创建本地会话壳，再插入消息。
4. `seq` 是会话内顺序，不能跨会话比较大小。
5. 撤回后 `content` 可能被服务端改写为系统提示 JSON，渲染应优先看 `status`。
6. 删除会话只影响当前用户视角，不代表消息从对端删除。

## 12. 常见错误码

| code | 含义 | 前端建议 |
| --- | --- | --- |
| `10001` | 参数验证失败 | 检查必填字段、枚举值、分页范围。 |
| `20001` | 未认证 | 跳转登录。 |
| `20004` | 权限不足 | 检查是否群成员或是否被禁言。 |
| `13001` | 消息不存在 | 刷新消息列表或提示消息已不可见。 |
| `13002` | 消息发送失败 | 允许重试，重试需复用 `clientMsgId`。 |
| `13003` | 消息类型不支持 | 检查 `msgType`。 |
| `13004` | 会话不存在 | 重新获取会话列表。 |
| `13005` | 消息内容为空 | 禁止发送空内容。 |
| `13006` | 消息内容过长 | 限制输入或压缩 payload。 |
| `13007` | 消息已撤回 | 更新本地撤回状态。 |
| `13008` | 消息已删除 | 从本地列表移除或置灰。 |
| `13009` | 撤回超时 | 提示超过撤回窗口。 |
| `13010` | 撤回无权限 | 隐藏撤回入口或提示无权限。 |
| `13011` | 消息重复 | 合并为首次发送结果，不重复展示。 |
| `14002` | 不是群成员 | 群聊发送时提示已不在群内。 |
| `14007` | 群组已解散 | 禁止继续发送群消息。 |
