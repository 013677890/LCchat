# 关系接口

本文描述好友关系、好友申请、好友同步、备注标签和黑名单接口。所有接口均需要登录态，响应结构遵循 [接口通用规范](00-接口通用规范.md)。字段名以 Gateway DTO 的 JSON 标签为准。

## 1. 模块约定

### 1.1 路由与认证

| 能力 | 路由前缀 | 是否需要登录 | 说明 |
| --- | --- | --- | --- |
| 好友 | `/api/v1/auth/friend` | 是 | 好友申请、好友列表、同步、备注、标签、关系查询。 |
| 黑名单 | `/api/v1/auth/blacklist` | 是 | 拉黑、取消拉黑、黑名单列表和拉黑关系查询。 |

所有接口必须携带：

```http
Authorization: Bearer <access_token>
X-Device-ID: <device_id>
```

### 1.2 枚举约定

| 枚举 | 值 | 说明 |
| --- | --- | --- |
| 好友申请状态 `status` | `-1` | 全部，仅列表筛选使用。 |
| 好友申请状态 `status` | `0` | 待处理。 |
| 好友申请状态 `status` | `1` | 已同意。 |
| 好友申请状态 `status` | `2` | 已拒绝。 |
| 处理动作 `action` | `1` | 同意申请。 |
| 处理动作 `action` | `2` | 拒绝申请。 |
| 关系 `relation` | `none` | 无关系。 |
| 关系 `relation` | `friend` | 已是好友。 |
| 关系 `relation` | `blacklist` | 存在拉黑关系。 |
| 关系 `relation` | `deleted` | 关系已删除。 |

### 1.3 通用对象

分页对象：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `page` | int32 | 当前页码。 |
| `pageSize` | int32 | 每页数量。 |
| `total` | int64 | 总记录数。 |
| `totalPages` | int32 | 总页数。 |

轻量用户对象 `targetInfo` / `SimpleUserInfo`：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `uuid` | string | 用户 UUID。 |
| `nickname` | string | 昵称。 |
| `avatar` | string | 头像 URL。 |
| `gender` | int32 | 性别。 |
| `signature` | string | 个性签名。 |

## 2. 发送好友申请

| 项 | 值 |
| --- | --- |
| 方法 | `POST` |
| 路径 | `/api/v1/auth/friend/apply` |
| 请求体 | JSON |
| 底层 RPC | `relation.FriendService.SendFriendApply` |
| 超时预算 | 2 秒 |

### 2.1 请求字段

| 字段 | 类型 | 必填 | 约束 | 说明 |
| --- | --- | --- | --- | --- |
| `targetUuid` | string | 是 | 非空 | 目标用户 UUID。 |
| `reason` | string | 否 | 最大 100 | 申请理由。 |
| `source` | string | 否 | 最大 20 | 来源，例如 `search`、`qrcode`。 |

### 2.2 请求示例

```json
{
  "targetUuid": "10000000000000000002",
  "reason": "我是小林",
  "source": "search"
}
```

### 2.3 data 返回字段

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `applyId` | int64 | 好友申请 ID，后续处理、标记已读使用。 |

## 20. 前端接入注意事项

1. `check`、`relation`、`blacklist/check` 当前 DTO 仍要求传 `userUuid`；前端应优先传当前登录用户 UUID，避免展示不一致。
2. 好友列表返回 `version`，客户端应保存该值，用于后续 `sync` 增量同步。
3. `sync` 返回 `hasMore=true` 时应继续用 `latestVersion` 或服务端约定的版本推进策略继续拉取，直到没有更多。
4. 删除好友、拉黑、取消拉黑成功后，应刷新会话页的关系状态和好友缓存。
5. 所有毫秒时间戳字段建议在前端统一转为本地时间展示。

## 21. 常见错误码

| code | 含义 | 前端建议 |
| --- | --- | --- |
| `10001` | 参数验证失败 | 检查必填字段、分页范围、数组非空。 |
| `20001` | 未认证 | 跳转登录。 |
| `20004` | 权限不足 | 禁止操作并提示无权限。 |
| `11001` | 用户不存在 | 提示目标用户不存在。 |
| `12001` | 已经是好友 | 不重复发送申请，刷新关系状态。 |
| `12002` | 好友申请已发送 | 展示“待通过”。 |
| `12003` | 不存在该好友关系 | 刷新好友列表。 |
| `12005` | 申请不存在或已处理 | 刷新申请列表。 |
| `12006` | 无权限处理该申请 | 禁止处理按钮。 |
| `12007` | 不能添加自己为好友 | 禁用自加好友入口。 |
| `12008` | 好友数量已达上限 | 提示无法继续添加。 |
| `12009` | 申请已过期 | 引导重新发送申请。 |
| `12010` | 标签名称无效 | 检查标签长度和字符。 |
| `12011` | 来源参数无效 | 使用约定来源值。 |
| `16001` | 对方已将你拉黑 | 提示无法操作或发送消息。 |
| `16002` | 你已将对方拉黑 | 提示先取消拉黑。 |
| `16003` | 已在黑名单中 | 刷新黑名单状态。 |
| `16004` | 不在黑名单中 | 刷新黑名单列表。 |
| `16005` | 不能拉黑自己 | 禁用自拉黑入口。 |
