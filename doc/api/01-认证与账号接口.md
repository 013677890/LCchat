# 认证与账号接口

本文是前端接入认证、账号安全和设备会话能力的接口手册。所有 HTTP 响应均遵循 [接口通用规范](00-接口通用规范.md) 的统一结构：业务数据位于 `data` 字段中。

## 1. 模块约定

### 1.1 路由与认证

| 类型 | 前缀 | 是否需要登录 | 说明 |
| --- | --- | --- | --- |
| 公开认证 | `/api/v1/public/user` | 否 | 注册、登录、验证码、刷新 Token、重置密码、解析二维码。 |
| 账号安全 | `/api/v1/auth/user` | 是 | 修改密码、换绑邮箱、注销、登出、设备管理。 |

认证接口需要 Header：

| Header | 必填 | 示例 | 说明 |
| --- | --- | --- | --- |
| `Authorization` | 是，认证接口必填 | `Bearer eyJ...` | Gateway JWT（JSON Web Token，访问令牌）鉴权。 |
| `X-Device-ID` | 登录、验证码登录建议必填 | `web-chrome-001` | 设备唯一 ID，用于 Token、设备会话、多端同步。 |

### 1.2 DeviceInfo

登录类接口可提交 `deviceInfo`。服务端会把设备信息写入设备会话，供“我的设备”和踢设备使用。

| 字段 | 类型 | 必填 | 约束 | 说明 |
| --- | --- | --- | --- | --- |
| `deviceName` | string | 否 | 最大 64 | 设备展示名称，例如 `iPhone 15`。 |
| `platform` | string | 否 | `iOS`、`Android`、`Web`、`Windows`、`Mac` | 客户端平台。 |
| `osVersion` | string | 否 | 最大 32 | 系统版本。 |
| `appVersion` | string | 否 | 最大 32 | 应用版本。 |

示例：

```json
{
  "deviceName": "Chrome on Windows",
  "platform": "Web",
  "osVersion": "Windows 11",
  "appVersion": "1.0.0"
}
```

## 2. 注册

### 2.1 基本信息

| 项 | 值 |
| --- | --- |
| 方法 | `POST` |
| 路径 | `/api/v1/public/user/register` |
| 认证 | 不需要 |
| 底层 RPC | `auth.AuthService.Register` |
| 超时预算 | 2 秒 |

### 2.2 请求字段

| 字段 | 类型 | 必填 | 约束 | 说明 |
| --- | --- | --- | --- | --- |
| `email` | string | 是 | 邮箱格式 | 注册邮箱。 |
| `password` | string | 是 | 6-20 位 | 登录密码。 |
| `verifyCode` | string | 是 | 6 位 | 邮箱验证码。 |
| `nickname` | string | 否 | 2-20 位 | 昵称；当前 DTO 标记为可选。 |
| `telephone` | string | 否 | 11 位 | 手机号；当前 DTO 标记为可选。 |

### 2.3 请求示例

```json
{
  "email": "user@example.com",
  "password": "12345678",
  "verifyCode": "123456",
  "nickname": "小林",
  "telephone": "13800138000"
}
```

### 2.4 data 返回字段

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `userUuid` | string | 注册生成的用户 UUID。 |
| `email` | string | 注册邮箱。 |
| `telephone` | string | 手机号。 |
| `nickname` | string | 昵称。 |

### 2.5 响应示例

```json
{
  "code": 0,
  "message": "success",
  "data": {
    "userUuid": "10000000000000000001",
    "email": "user@example.com",
    "telephone": "13800138000",
    "nickname": "小林"
  },
  "trace_id": "trace-xxx",
  "timestamp": 1710000000
}
```

## 3. 密码登录

### 3.1 基本信息

| 项 | 值 |
| --- | --- |
| 方法 | `POST` |
| 路径 | `/api/v1/public/user/login` |
| 认证 | 不需要 |
| Header | 建议携带 `X-Device-ID` |
| 底层 RPC | `auth.AuthService.Login` |
| 超时预算 | 2 秒 |

### 3.2 请求字段

| 字段 | 类型 | 必填 | 约束 | 说明 |
| --- | --- | --- | --- | --- |
| `account` | string | 是 | 非空 | 邮箱或手机号。 |
| `password` | string | 是 | 6-20 位 | 密码。 |
| `deviceInfo` | object | 否 | 见 1.2 | 设备信息。 |

### 3.3 请求示例

```json
{
  "account": "user@example.com",
  "password": "12345678",
  "deviceInfo": {
    "deviceName": "Chrome on Windows",
    "platform": "Web",
    "osVersion": "Windows 11",
    "appVersion": "1.0.0"
  }
}
```

### 3.4 data 返回字段

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `accessToken` | string | 访问令牌，后续 HTTP 认证和 WebSocket 握手使用。 |
| `refreshToken` | string | 刷新令牌。 |
| `tokenType` | string | 令牌类型，通常为 `Bearer`。 |
| `expiresIn` | int64 | AccessToken 剩余有效期，单位秒。 |
| `userInfo` | object | 登录态最小用户资料。 |
| `userInfo.uuid` | string | 用户 UUID。 |
| `userInfo.nickname` | string | 昵称。 |
| `userInfo.avatar` | string | 头像 URL。 |

### 3.5 响应示例

```json
{
  "code": 0,
  "message": "success",
  "data": {
    "accessToken": "access-token",
    "refreshToken": "refresh-token",
    "tokenType": "Bearer",
    "expiresIn": 604800,
    "userInfo": {
      "uuid": "10000000000000000001",
      "nickname": "小林",
      "avatar": "https://example.com/avatar.png"
    }
  },
  "trace_id": "trace-xxx",
  "timestamp": 1710000000
}
```

## 8. 重置密码

| 项 | 值 |
| --- | --- |
| 方法 | `POST` |
| 路径 | `/api/v1/public/user/reset-password` |
| 认证 | 不需要 |

请求字段：

| 字段 | 类型 | 必填 | 约束 | 说明 |
| --- | --- | --- | --- | --- |

## 9. 修改密码

| 项 | 值 |
| --- | --- |
| 方法 | `POST` |
| 路径 | `/api/v1/auth/user/change-password` |
| 认证 | 需要 |
| 限流 | 敏感操作限流，默认 2 rps、burst 5 |

请求字段：

| 字段 | 类型 | 必填 | 约束 | 说明 |
| --- | --- | --- | --- | --- |
| `oldPassword` | string | 是 | 当前 DTO 为 8-16 位 | 旧密码。 |
| `newPassword` | string | 是 | 当前 DTO 为 8-16 位 | 新密码。 |

成功时 `data=null`。

## 11. 注销账号

| 项 | 值 |
| --- | --- |
| 方法 | `POST` |
| 路径 | `/api/v1/auth/user/delete-account` |
| 认证 | 需要 |
| 限流 | 敏感操作限流 |

请求字段：

| 字段 | 类型 | 必填 | 约束 | 说明 |
| --- | --- | --- | --- | --- |
| `password` | string | 是 | 6-20 位 | 当前账号密码。 |
| `reason` | string | 否 | 最大 255 | 注销原因。 |

响应字段：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `deleteAt` | string | 注销受理时间。 |
| `recoverDeadline` | string | 恢复截止时间。 |

注销成功后，auth 同步标删账号并清 Token，下游资料、关系、群等通过 `account.deleted` 最终一致清理。

## 13. 设备列表

| 项 | 值 |
| --- | --- |
| 方法 | `GET` |
| 路径 | `/api/v1/auth/user/devices` |
| 认证 | 需要 |

响应字段：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `devices` | array | 设备列表。 |
| `devices[].deviceId` | string | 设备 ID。 |
| `devices[].deviceName` | string | 设备名称。 |
| `devices[].platform` | string | 平台。 |
| `devices[].appVersion` | string | 应用版本。 |
| `devices[].isCurrentDevice` | bool | 是否当前设备。 |
| `devices[].status` | int32 | 0 在线，1 离线，2 注销，3 被踢出。 |
| `devices[].lastSeenAt` | string | RFC3339 格式最后活跃时间：在线设备为心跳时间，离线设备为最后一次登录/断连/登出时刻。 |

## 14. 踢出设备

| 项 | 值 |
| --- | --- |
| 方法 | `DELETE` |
| 路径 | `/api/v1/auth/user/devices/:deviceId` |
| 认证 | 需要 |

路径参数：

| 参数 | 说明 |
| --- | --- |

## 15. 在线状态

### 15.1 查询单人在线状态

| 项 | 值 |
| --- | --- |
| 方法 | `GET` |
| 路径 | `/api/v1/auth/user/online-status/:userUuid` |
| 认证 | 需要 |

响应字段：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `userUuid` | string | 用户 UUID。 |
| `isOnline` | bool | 是否在线：该用户在 presence 窗口（默认 120 秒）内存在存活 WebSocket 连接；纯 HTTP 活跃不算在线。 |
| `lastSeenAt` | string | RFC3339 格式最后活跃时间：在线取心跳时间，离线取最后状态迁移时刻。 |
| `onlinePlatforms` | string[] | 在线平台列表。 |

### 15.2 批量查询在线状态

| 项 | 值 |
| --- | --- |
| 方法 | `POST` |
| 路径 | `/api/v1/auth/user/batch-online-status` |
| 认证 | 需要 |

请求字段：

| 字段 | 类型 | 必填 | 约束 | 说明 |
| --- | --- | --- | --- | --- |
| `userUuids` | string[] | 是 | 1-100 个 | 目标用户 UUID 列表。 |

响应字段：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `users` | array | 用户在线状态列表。 |
| `users[].userUuid` | string | 用户 UUID。 |
| `users[].isOnline` | bool | 是否在线（语义同单人查询：需存活 WebSocket 连接）。 |
| `users[].lastSeenAt` | string | RFC3339 格式最后活跃时间。 |

## 16. 常见错误码

| code | 含义 | 前端建议 |
| --- | --- | --- |
| `10001` | 参数验证失败 | 检查字段名、必填项和长度。 |
| `10005` | 请求过于频繁 | 展示稍后重试。 |
| `20001` | 未认证 | 跳转登录。 |
| `20002` | Token 无效 | 清理本地登录态并重新登录。 |
| `20003` | Token 已过期 | 尝试刷新 Token，失败后重新登录。 |
| `11003` | 密码错误 | 提示密码错误。 |
| `11006` | 验证码错误 | 提示重新输入。 |
| `11007` | 验证码已过期 | 引导重新发送验证码。 |
| `11017` | 账号不存在 | 引导注册或检查账号。 |
| `11029` | 账号已注销 | 禁止登录并提示账号状态。 |
| `15004` | 设备会话不存在 | 刷新设备列表。 |
| `15005` | 不能踢出当前设备 | 禁用当前设备的踢出按钮。 |
