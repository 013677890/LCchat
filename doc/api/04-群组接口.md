# 群组接口
本文描述群创建、资料维护、入群申请、审批、成员管理、禁言和解散接口。所有接口均需要登录态，响应结构遵循 [接口通用规范](00-接口通用规范.md)。字段名以 Gateway DTO 的 JSON 标签为准。

## 1. 模块约定
### 1.1 路由与认证
| 项 | 值 |
| --- | --- |
| 路由前缀 | `/api/v1/auth/groups` |
| 认证 | 必须携带 `Authorization: Bearer <access_token>` |
| 设备 | 建议携带 `X-Device-ID` |
| 底层服务 | `group.GroupService` |
| 缓存一致性 | 写操作通过 group outbox 产生 `group.cache` 事件，Redis 投影最终一致更新。 |
### 1.2 枚举约定
| 枚举 | 值 | 说明 |
| --- | --- | --- |
| 群加入方式 `addMode` | `0` | 允许直接入群，服务端可能直接返回 `joinedDirectly=true`。 |
| 群加入方式 `addMode` | `1` | 需要审批。 |
| 群角色 `role` | `0` | 普通成员。 |
| 群角色 `role` | `1` | 管理员。 |
| 入群申请状态 `status` | `0` | 待处理。 |
| 入群申请状态 `status` | `1` | 已同意。 |
| 入群申请状态 `status` | `2` | 已拒绝。 |
| 入群申请状态 `status` | `3` | 已取消或已失效。 |
| 审批动作 `action` | `1` | 同意。 |
| 审批动作 `action` | `2` | 拒绝。 |
### 1.3 通用对象
`GroupInfoDTO`：
| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `groupUuid` | string | 群 UUID。 |
| `name` | string | 群名称。 |
| `avatar` | string | 群头像 URL。 |
| `notice` | string | 群公告。 |
| `ownerUuid` | string | 群主 UUID。 |
| `memberCount` | int32 | 当前成员数。 |
| `addMode` | int32 | 入群方式，见 1.2。 |
| `muteAll` | bool | 是否全员禁言。 |
`GroupMemberItemDTO`：
| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `userUuid` | string | 成员用户 UUID。 |
| `role` | int32 | 成员角色：0 普通成员，1 管理员。 |
| `nickname` | string | 用户昵称。 |
| `avatar` | string | 用户头像。 |
| `groupNickname` | string | 群名片。 |
| `muteUntil` | int64 | 单人禁言截止时间，Unix 毫秒；0 表示未禁言。 |
## 2. 创建群
| 项 | 值 |
| --- | --- |
| 方法 | `POST` |
| 路径 | `/api/v1/auth/groups` |
| 请求体 | JSON |
| 底层 RPC | `group.GroupService.CreateGroup` |
| 超时预算 | 2 秒 |
### 2.1 请求字段
| 字段 | 类型 | 必填 | 约束 | 说明 |
| --- | --- | --- | --- | --- |
| `name` | string | 是 | 1-64 位 | 群名称。 |
| `avatar` | string | 否 | - | 群头像 URL。 |
| `memberUuids` | string[] | 否 | 服务端校验邀请数量 | 初始邀请成员 UUID 列表，不需要包含当前登录用户。 |
### 2.2 请求示例
```json

{

  "name": "LCChat 技术交流群",

  "avatar": "https://cdn.example.com/group.png",

  "memberUuids": ["10000000000000000002", "10000000000000000003"]

}
```

### 2.3 data 返回字段
| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `groupUuid` | string | 新创建群 UUID。 |

## 29. 前端接入注意事项
1. 群写操作成功后，Redis 群缓存通过 outbox 异步投影更新；接口成功不代表所有读缓存立即可见，前端可乐观更新本地状态。
2. 群资料的 `addMode`、`muteAll`、成员 `role` 和 `muteUntil` 会影响消息发送权限，发送消息失败时需结合错误码刷新群状态。
3. 群搜索接口仅支持“按群名模糊匹配”或“按完整群号精确匹配”；空关键字不会返回全量群。
4. 成员列表接口当前不分页，群规模变大时前端应优先使用搜索接口或成员 ID 列表做轻量判断。
5. 入群申请列表的时间字段均为 Unix 毫秒，展示前统一转本地时间。
6. 管理员操作前端应根据当前用户角色隐藏按钮，但最终权限以服务端校验为准。
7. 群消息发送若收到 `14002`、`14017`、`14018`，应立即刷新群资料和当前成员权限状态。

## 30. 常见错误码
| code | 含义 | 前端建议 |
| --- | --- | --- |
| `10001` | 参数验证失败 | 检查路径参数、分页、必填字段。 |
| `20001` | 未认证 | 跳转登录。 |
| `20004` | 权限不足 | 隐藏或禁用管理操作。 |
| `14001` | 群组不存在 | 移除本地群入口或提示群不存在。 |
| `14002` | 不是群成员 | 禁止访问群详情和发送消息。 |
| `14003` | 没有权限 | 提示需要管理员或群主权限。 |
| `14004` | 群成员已满 | 提示无法加入或邀请。 |
| `14005` | 群名称过长 | 限制名称长度。 |
| `14006` | 群公告过长 | 限制公告长度。 |
| `14007` | 群组已解散 | 关闭群页面或展示解散状态。 |
| `14008` | 群成员不存在 | 刷新成员列表。 |
| `14009` | 不能踢出群主 | 禁用踢群主按钮。 |
| `14010` | 不能踢出管理员 | 按角色禁用操作。 |
| `14011` | 已经是群成员 | 不重复申请或邀请。 |
| `14012` | 入群申请不存在或已处理 | 刷新审批列表。 |
| `14013` | 邀请人数超限 | 拆分邀请或减少选择数量。 |
| `14014` | 群主不能退群 | 引导转让或解散。 |
| `14015` | 管理员数量已达上限 | 禁止继续设置管理员。 |
| `14016` | 已存在待处理入群申请 | 展示待审批状态。 |
| `14017` | 群聊已开启全员禁言 | 刷新群资料并禁用普通成员发送入口。 |
| `14018` | 当前成员已被禁言 | 刷新成员状态并提示禁言剩余时间。 |
