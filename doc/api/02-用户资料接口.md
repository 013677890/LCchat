# 用户资料接口

本文描述用户资料、搜索、头像、二维码和批量资料查询接口。所有接口均通过 Gateway 暴露，响应结构遵循 [接口通用规范](00-接口通用规范.md)。字段名以 `apps/gateway/internal/dto` 中的 JSON 标签为准。

## 1. 模块约定

### 1.1 路由与认证

| 类型 | 前缀 | 是否需要登录 | 说明 |
| --- | --- | --- | --- |
| 公开二维码 | `/api/v1/public/user` | 否 | 当前只有解析二维码接口。 |
| 用户资料 | `/api/v1/auth/user` | 是 | 当前登录用户资料、他人资料、搜索、头像、二维码和批量资料。 |

认证接口必须携带：

```http
Authorization: Bearer <access_token>
X-Device-ID: <device_id>
```

### 1.2 通用用户对象

`UserProfile` 用于完整资料展示：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `uuid` | string | 用户 UUID。 |
| `nickname` | string | 昵称。 |
| `avatar` | string | 头像 URL。 |
| `gender` | int8 | 性别：1 男，2 女，3 未知。 |
| `signature` | string | 个性签名。 |
| `birthday` | string | 生日，建议前端按 `YYYY-MM-DD` 处理。 |

`SimpleUserInfo` 用于批量资料、好友列表等轻量展示：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `uuid` | string | 用户 UUID。 |
| `nickname` | string | 昵称。 |
| `avatar` | string | 头像 URL。 |
| `gender` | int32 | 性别：1 男，2 女，3 未知。 |
| `signature` | string | 个性签名。 |

分页对象 `pagination`：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `page` | int32 | 当前页码。 |
| `pageSize` | int32 | 每页数量。 |
| `total` | int64 | 总记录数。 |
| `totalPages` | int32 | 总页数。 |

## 2. 获取当前用户资料

| 项 | 值 |
| --- | --- |
| 方法 | `GET` |
| 路径 | `/api/v1/auth/user/profile` |
| 认证 | 需要 |
| 请求参数 | 无 |
| 底层 RPC | `user.UserService.GetProfile` |
| 超时预算 | 1 秒 |

### 2.1 data 返回字段

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `userInfo` | object | 当前登录用户完整资料。 |
| `userInfo.uuid` | string | 用户 UUID。 |
| `userInfo.nickname` | string | 昵称。 |
| `userInfo.avatar` | string | 头像 URL。 |
| `userInfo.gender` | int8 | 性别：1 男，2 女，3 未知。 |
| `userInfo.signature` | string | 个性签名。 |
| `userInfo.birthday` | string | 生日。 |

### 2.2 响应示例

```json
{
  "code": 0,
  "message": "success",
  "data": {
    "userInfo": {
      "uuid": "10000000000000000001",
      "nickname": "小林",
      "avatar": "https://cdn.example.com/avatar.png",
      "gender": 1,
      "signature": "保持热爱",
      "birthday": "2000-01-01"
    }
  },
  "trace_id": "trace-xxx",
  "timestamp": 1710000000
}
```

## 3. 更新当前用户资料

| 项 | 值 |
| --- | --- |
| 方法 | `PUT` |
| 路径 | `/api/v1/auth/user/profile` |
| 认证 | 需要 |
| 请求体 | JSON |
| 底层 RPC | `user.UserService.UpdateProfile` |
| 超时预算 | 1 秒 |

### 3.1 请求字段

至少提交一个可更新字段；全部为空会返回参数错误。

| 字段 | 类型 | 必填 | 约束 | 说明 |
| --- | --- | --- | --- | --- |
| `nickname` | string | 否 | 2-20 位 | 新昵称。 |
| `gender` | int32 | 否 | 1、2、3 | 性别：1 男，2 女，3 未知。 |
| `birthday` | string | 否 | 服务端校验日期格式 | 生日，建议使用 `YYYY-MM-DD`。 |
| `signature` | string | 否 | 最大 100 | 个性签名。 |

### 3.2 请求示例

```json
{
  "nickname": "小林同学",
  "gender": 1,
  "birthday": "2000-01-01",
  "signature": "今天也要写好代码"
}
```

### 3.3 data 返回字段

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `userInfo` | object | 更新后的完整资料，字段同 `UserProfile`。 |

## 5. 搜索用户

| 项 | 值 |
| --- | --- |
| 方法 | `GET` |
| 路径 | `/api/v1/auth/user/search` |
| 认证 | 需要 |
| 参数来源 | Query |
| 底层 RPC | `user.UserService.SearchUser` |
| 超时预算 | 3 秒 |

### 5.1 Query 参数

| 参数 | 类型 | 必填 | 默认值 | 约束 | 说明 |
| --- | --- | --- | --- | --- | --- |
| `keyword` | string | 是 | - | 1-20 位 | 搜索关键字，可用于邮箱、昵称、用户 ID。 |
| `page` | int32 | 否 | 1 | >= 1 | 页码。 |
| `pageSize` | int32 | 否 | 100 | 1-100 | 每页数量；当前 Gateway 默认 100。 |

示例：

```http
GET /api/v1/auth/user/search?keyword=lin&page=1&pageSize=20
```

### 5.2 data 返回字段

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `items` | array | 搜索结果列表。 |
| `items[].uuid` | string | 用户 UUID。 |
| `items[].nickname` | string | 昵称。 |
| `items[].avatar` | string | 头像 URL。 |
| `items[].signature` | string | 个性签名。 |
| `items[].isFriend` | bool | 是否已经是好友。 |
| `pagination` | object | 分页信息。 |

## 6. 上传头像

| 项 | 值 |
| --- | --- |
| 方法 | `POST` |
| 路径 | `/api/v1/auth/user/avatar` |
| 认证 | 需要 |
| 请求体 | `multipart/form-data` |
| 表单字段 | `avatar` |
| 底层依赖 | MinIO + `user.UserService.UploadAvatar` |
| 超时预算 | 3 秒 |

### 6.1 表单字段

| 字段 | 类型 | 必填 | 约束 | 说明 |
| --- | --- | --- | --- | --- |
| `avatar` | file | 是 | 最大 2MB；仅 `image/jpeg`、`image/png` | 头像图片文件。 |

前端示例：

```js
const form = new FormData();
form.append('avatar', file);
await fetch('/api/v1/auth/user/avatar', {
  method: 'POST',
  headers: { Authorization: `Bearer ${token}` },
  body: form
});
```

### 6.2 data 返回字段

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `avatarUrl` | string | 上传后可访问的头像 URL。 |

### 6.3 常见失败

| code | 含义 | 前端建议 |
| --- | --- | --- |
| `10001` | 未提交 `avatar` 字段 | 提示选择图片。 |
| `10006` | 文件超过 2MB | 提示压缩或重新选择。 |
| `11011` | 文件格式不支持 | 只允许 JPG/PNG。 |
| `11012` | 文件上传失败 | 提示稍后重试。 |

## 10. 前端接入注意事项

1. 当前资料更新接口使用普通字段语义，未传字段与空值字段都可能被服务端按 DTO 零值处理；前端应只提交用户实际修改的字段。
2. 头像上传不要手动设置 `Content-Type: multipart/form-data`，交给浏览器自动附带 boundary。
3. 用户搜索默认 `pageSize=100`，移动端建议显式传 `pageSize=20` 降低渲染压力。
4. 二维码解析是公开接口，但解析结果只返回 UUID；加好友仍需走好友申请接口。

## 11. 常见错误码

| code | 含义 | 前端建议 |
| --- | --- | --- |
| `10001` | 参数验证失败 | 检查必填、长度、分页范围。 |
| `10006` | 请求体过大 | 上传头像时压缩图片。 |
| `20001` | 未认证 | 跳转登录。 |
| `20002` | Token 无效 | 清理本地登录态。 |
| `11001` | 用户不存在 | 提示用户不存在或资料已不可见。 |
| `11010` | 昵称已被使用 | 提示更换昵称。 |
| `11011` | 文件格式不支持 | 只允许 JPG/PNG。 |
| `11012` | 文件上传失败 | 提示稍后重试。 |
| `11013` | 二维码格式错误 | 提示二维码无效。 |
| `11014` | 二维码已过期 | 引导重新生成二维码。 |
| `11021` | 个性签名过长 | 限制输入长度。 |
| `11022` | 生日格式错误 | 使用 `YYYY-MM-DD`。 |
| `11023` | 性别值无效 | 只传 1、2、3。 |
